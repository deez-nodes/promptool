# PROMPTOOL & REVX IDE Documentation

This directory contains the complete design system specification, design tokens, TypeScript schemas, and the spec-driven development plan for building **PROMPTOOL** as a standalone Prompt Engineering IDE in Nuxt 3.

## Contents

- **[DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)**: Color token extraction, hex/RGB/HSL values, optical glows, typography hierarchies, Tailwind CSS configuration, and CSS custom properties.
- **[PROMPTOOL_SPEC.md](./PROMPTOOL_SPEC.md)**: Full spec-driven development plan, Nuxt 3 module architecture, component breakdown, AST compiler specifications, and sprint milestones.
- **[tokens.json](./tokens.json)**: Machine-readable Design Token JSON definition.
- **[types.ts](./types.ts)**: Complete TypeScript types and domain schemas for prompt documents, sections, variables, and term bank items.
